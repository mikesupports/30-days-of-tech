**What I did:** Reviewed the Intro to DevOps class: the lifecycle, CALMS, and the CI/CD terms.

**What confused me:** [one real thing]

**What I learned:**

- Lifecycle: Plan, Code, Build, Test, Release, Deploy, Operate, Monitor. Monitoring feeds back into planning, so it's a loop.
- CALMS: Culture, Automation, Lean, Measurement, Sharing.
- Continuous Integration: merge code changes often and test them automatically.
- Continuous Delivery: code is always ready to release, but a person decides when.
- Continuous Deployment: code goes live on its own once the tests pass.

**Soil science link:** A farming season is also a loop. Soil test results decide what happens next season, much like monitoring decides what gets changed next.
