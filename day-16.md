# Day 16

**What I did:** Guided lab in class: whoami, pwd, ls -a in /etc, cd to /var/log with an absolute path, cd ~, ls -l.

**What confused me:** installation of tree

**What I learned:**
- whoami: who I am. pwd: where I am.
- /etc holds configuration files. ls -a shows hidden files (names starting with a dot).
- /var/log holds system logs.
- An absolute path starts with / and works from anywhere.
- cd ~ goes back to my home folder, /home/mike.
- ls -l is the long listing. My home folder is empty, so it shows total 0.

**Also:** My prompt shows mike@..., not root@.... Fixed the root login from Day 14.
